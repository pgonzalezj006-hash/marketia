Prompts y uso práctico

Los mejores prompts de ChatGPT para negocios (con ejemplos)

22 de septiembre de 2026 · Lectura de 7 minutos

Un buen prompt es la diferencia entre un resultado genérico y uno que de verdad puedes usar. Aquí tienes una colección organizada por tarea, lista para copiar y adaptar con los datos reales de tu negocio.

Prompts para redes sociales

"Escribe 3 versiones de un post para [red social] anunciando [producto/servicio/oferta]. El tono es [cercano / profesional / divertido]. Mi negocio es [descripción breve] y mi cliente típico es [descripción del cliente]."

"Convierte este texto largo en un hilo de 5 publicaciones cortas para redes sociales: [pega tu texto]."

Prompts para atención al cliente

"Responde a esta reseña de forma profesional y cercana, agradeciendo el comentario y sin sonar a plantilla genérica: [pega la reseña]."

"Escribe una respuesta educada para un cliente molesto por [motivo], reconociendo el problema sin admitir responsabilidad legal, y ofreciendo [solución concreta]."

Prompts para email marketing

"Escribe un correo anunciando [oferta/novedad] a clientes que ya nos compraron antes. Asunto corto y directo, cuerpo de máximo 150 palabras, con una única llamada a la acción."

Prompts para ventas

"Escribe una descripción de producto para [producto], destacando [beneficio principal] para un cliente que busca [necesidad concreta]. Máximo 80 palabras."

"Resume estas notas de una llamada de ventas en 3 puntos clave y sugiere un siguiente paso: [pega las notas]."

Cómo mejorar cualquier prompt de esta lista

  • Reemplaza cada corchete con información real, nunca genérica
  • Pide explícitamente el tono que quieres (cercano, formal, divertido, etc.)
  • Define un límite de longitud — sin límite, la IA tiende a alargarse de más
  • Si el primer resultado no sirve, pide ajustes concretos en vez de empezar de cero

Preguntas frecuentes

¿Por qué mi resultado no se parece al ejemplo?

Reemplaza los datos entre corchetes por información real y específica de tu negocio — cuanto más concreto, mejor el resultado.

¿Puedo pedirle que ajuste el resultado?

Sí, y deberías hacerlo. Pide cambios de tono, longitud o énfasis como si hablaras con un redactor real.
